# Amazon Sales Analysis Dashboard

An interactive sales analysis dashboard built using Microsoft Excel to analyze Amazon sales performance, order trends, cancellations, product categories, and fulfillment channels.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track order volume and quantity sold.
- Monitor cancelled orders and cancellation rates.
- Identify top-performing product categories and styles.
- Compare Amazon and Merchant fulfillment sales.
- Understand monthly sales trends.

## 📌 Key Performance Indicators

- Total Orders: 128,975
- Total Sales: ₹78.59M
- Total Quantity: 116,649
- Cancelled Orders: 18,332
- Cancellation Rate: 14.21%
- Average Order Value: ₹609.36

## 🔍 Key Insights

- Set and Kurta are the leading product categories.
- Monthly sales declined from April to June in the displayed period.
- Approximately 14% of orders were cancelled.
- Amazon fulfillment generated higher sales than Merchant fulfillment.
- The top 10 styles contributed approximately 15.6% of total sales.
